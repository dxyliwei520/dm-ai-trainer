## 二、6 个真 bug（都踩实了，附根因与判据）

### bug 1 · 页面状态冻结：JSON 接口被浏览器缓存

- **现象**：训练早就结束了，页面一直显示「训练中」，于是「开始训练」永远灰着点不动。
- **根因**：FastAPI 的 JSON 响应默认**没有** `Cache-Control`，浏览器对 GET 做启发式缓存，`/api/status` 直接命中缓存。
- **修法**：加 HTTP 中间件，所有 `/api/*` 响应带 `no-store, no-cache, must-revalidate, max-age=0`；前端轮询再加 `cache:'no-store'` + 时间戳。
- **判据**：`curl -D - /api/status` 能看到 `cache-control: no-store...`。

### bug 2 · 删 DOM 元素却没删 JS 绑定 → 后面所有按钮全失效（最坑）

- **现象**：点「开始训练」毫无反应，控制台报 `TypeError: Cannot set properties of null (setting 'onclick')`。
- **根因**：删「批量填 caption / 校验素材」那一行时，把紧随其后的「删除按钮组」**一起删了**（同一次字符串区间删除），
  而 JS 仍在 `$('btnClearAll').onclick = ...` → 第一个 null 抛异常 → **同文件后面所有绑定（含 btnTrain）都没执行**。
- **修法**：恢复按钮行；新增 `domCheck()`，启动时校验 60+ 必需元素，缺任何一个直接在顶部红条报出名字。
- **判据**：无头浏览器里 `typeof btnTrain.onclick === 'function'`，且 `Runtime.exceptionThrown` 为空。
- **教训**：**删 HTML 必须同步删 JS 绑定**；任何一批绑定都要能容忍个别元素缺失。

### bug 3 · 删函数连带删掉 `refreshStatus()`，整页状态不再刷新

- **现象**：进度条、LoRA 列表、样张、清理报告都不更新。
- **根因**：用「从 A 字符串截到下一个 `$('btn…`」的方式删事件处理，把紧随其后的 `async function refreshStatus()` 一起吃掉。
- **修法**：完整补回该函数；**按行号/明确边界替换**，别用"下一个按钮"这种模糊锚点。
- **判据**：页面里 `async function refreshStatus` 存在，且 2 秒轮询后数字变化。

### bug 4 · patch 脚本把模板字符串的反引号吃掉

- **现象**：改完 `node --check` 直接报 `Invalid or unexpected token`。
- **根因**：用 PowerShell 双引号字符串拼 JS，`` ` `` 是 PS 的转义符，写进文件后反引号消失，`` `${name}` `` 变裸文本。
- **修法**：**JS 片段一律用 Python 写文件**（或 `@'…'@` 单引号 here-string），PS 只负责调用。
- **判据**：每次改完都跑 `node --check`（本次就是靠它兜住的）。

### bug 5 · 重复装饰器：`@app.post("/api/install")@app.post("/api/install")`

- **现象**：服务起不来，`TypeError: unsupported operand type(s) for @: 'function' and 'function'`。
- **根因**：用「截到某个锚点」插入新接口时，锚点本身既留在新文本末尾、又保留在原处。
- **修法**：去重；插入类改动优先按行号切片，而不是字符串锚点。
- **判据**：`py_compile` 通过 **并且** `curl /` 返回 200（编译通过不代表能起服务）。

### bug 6 · 重启网页会带走正在跑的训练

- **现象**：重启 8198 后，训练进程消失、日志停在 `Model Loaded`。
- **根因**：训练是网页进程的子进程，父进程被 kill 时子进程一起结束。
- **修法（已部分缓解）**：前端改动走热重载（读 `ui.html` 每次请求）；后端改动仍必须重启，**重启前先查 `run.py` 进程**。
- **未做**：把训练改成脱离网页的独立进程（`schtasks` 拉起）——已列入待办。

## 三、今天验证过的数据（RTX 5070 Ti 16 GB / 32 GB RAM）

## 五、一句话总结

> 这一天主要不是"加功能"，而是**把改动做安全**：删除要成对（HTML+JS）、插入要有明确边界、
> 改完必须用 `node --check` / `py_compile` / 无头浏览器**三重验证**，
> 并且所有接口和页面都要 `no-store` —— 否则用户看到的是缓存里的旧世界。
