## 一、这是什么

一个**本地网页训练台**，用 ai-toolkit 的 `qwen_image_2` 扩展，在 Qwen-Image-2.1 上训练**图片编辑 LoRA**（图生图：给一张图 + 一句指令 → 输出改后的图）。

| 事实 | 值 |
|---|---|
| 训练后端 | ai-toolkit（`env-aitk`）—— 只有它支持 2.1 |
| 底座 | F 盘 ComfyUI 现成的 `qwen_image_2.1_int8_convrot.safetensors`（6.76 GB），**不需要额外下 30 GB** |
| 显存 | 16 GB 卡，训练时约 12 GB（必须停 ComfyUI 8189） |
| 速度 | 512×512 = **2.4 秒/步**；1024 约 3~4 倍慢 |
| 产物 | `.safetensors` 约 76 MB（rank 16），直接给 ComfyUI 的 `LoraLoader` 用 |

**它不是什么**：不是文生图风格 LoRA（那种只要成品图，不需要配对），也不是模型本体微调（原权重一个字节都不动）。

## 二、启动与停止

```
双击  E:\ai-train\_START_WEBUI_QWEN.bat
      → 3 秒后自动打开 http://127.0.0.1:8198
      → 关掉那个黑窗口 = 服务停止
```

| 情况 | 表现 |
|---|---|
| 已经在跑时又双击 | 不会起第二份，只打开浏览器（防重复启动） |
| 想换端口 | 停掉后设 `QWEN_TRAIN_PORT=8197` 再启动 |
| 打不开页面 | 看黑窗口有没有报错；99% 是 8198 被占或 python 路径不对 |

> **后端和网页是同一个进程**（FastAPI 同时提供页面和接口），所以只有这一个 BAT。
> ⚠️ 「打开文件夹」这类按钮要求服务跑在**你自己的桌面会话**里（双击 BAT 即是）；后台/远程起的服务点了不会弹窗，此时复制页面上的路径即可。
> 判断页面是否最新：页头右侧有一行 `build 2026-11-10 xx:xx`。

## 三、界面怎么用（5 个区块）

> 页头右上角始终有两个快捷按钮：**📂 素材**（打开 `datasets\\<项目>`）、**📂 输出**（打开 `runs\\<项目>`）。

### 1 · 新建训练文件夹

- 输入框填名字（如 `qwen_商品白底`）→ 点「**新建**」→ 自动建好 `datasets\\<项目>\\control`、`target` 和 `runs\\<项目>`
- 切已有项目：直接用左边的下拉框（下拉里会显示「N/N 对」）
- 下方三行路径各带「打开」：素材 / 输出 / 配方
- 页面加载时会**自动选中并打开**下拉里的第一个项目

### 2 · 素材（一组 = 参考图 1~4 + 目标图 A + 指令）

```
┌ 正在上传 003 组 ──────────────────────────────────────────┐
│ 参考图1  参考图2  参考图3  参考图4                          │
│ 目标图A   指令 [图1和图2的女生站在一起        ]  [⬆ 上传这一组] │
└───────────────────────────────────────────────────────────┘
删除（会先移到项目内 _deleted\\，可手动恢复）：[🗑 一键清空全部素材] [只清 control] [只清 target] [清空回收站]
[配对卡片…]
```

点**一次**「⬆ 上传这一组」自动落盘：

| 你选的 | 存成 |
|---|---|
| 参考图1 | `control\\001_a.png` |
| 参考图2 | `control\\001_b.png` |
| 参考图3 / 4 | `control\\001_c.png` / `001_d.png`（不选就不生成） |
| 目标图 A | `target\\001.png` |
| 指令 | `target\\001.txt` |

传完表单自动清空、组号变 002，接着传下一组即可（003、004…自动递增）。

**自动质检**（不需要点按钮）：上传完、切换项目时各跑一次。通过只显示一行绿字；有问题才展开清单：

| 检查项 | 判定 |
|---|---|
| 参考图与 target 是否同名配对 | 错误 |
| 缺 target / 缺参考图 / 缺 caption | 错误 |
| **caption 提到「图2」但只配了 1 张参考图** | 错误（很常见，见 §八） |
| 参考图之间是同一张（MD5 相同） | 错误 |
| target 与某张参考图完全相同 | 错误（等于教模型"别改"） |
| 各对参考图张数不一致 | 提醒 |
| 多图但 caption 没有「图1/图2」指代 | 提醒 |
| 尺寸不是 16 倍数 / 少于 30 对 | 提醒 |

**配对卡片**：左边 1~4 张参考图（带 `图1/图2` 角标，hover 出 ✕ 单删），右边 target；缺任何一边红框。卡片里那行输入框就是 caption，**打完字即自动保存成 `target\\<组号>.txt`**。

### 3 · 训练参数

| 控件 | 说明 |
|---|---|
| **底座模型** | 只列 Qwen-Image 2.1（其它权重置灰）；「刷新模型」重扫，「打开模型目录」弹资源管理器。想加新底座：丢进 `E:\\ai-train\\models\\dit` |
| 步数 | 30 对 → 1000~1500；2 对测链路 → 20~100 |
| rank | 16（复杂改图 32） |
| lr | 1e-4（不收敛降 5e-5） |
| 分辨率 | 512 快（2.4 秒/步）；1024 慢 3~4 倍 |
| 存档间隔 | 250（每 N 步一档，挑最好的用） |
| ☑ 训练前停 ComfyUI(8189) | **必须勾**，16 GB 显存 |
| ☐ 跳过基线样张 | 快速测试勾上，省约 1 分钟 |
| ☐ 训练后不恢复 ComfyUI | 想独显给别人时勾，之后可一键恢复 |

### 4 · 进度

- `step / 总步数`、`loss`、已用时间、进度条
- **阶段行**（日志框上方）：`正在加载 DiT 主模型` → `正在加载文本编码器（CPU 反量化，1~4 分钟）` → `正在缓存文本向量` → `训练中` → `正在生成样张` → `正在保存 LoRA`
- 日志框：训练器原始输出（按项目取，训练停了也能看）
- 训练中「开始训练」**变灰不可点**、文案 `训练中… 37%`；「停止」高亮可点
- 训练结束显示自动清理报告与「恢复 ComfyUI」按钮（如被留成关闭）

### 5 · 产物

| 按钮 | 打开/执行 |
|---|---|
| 📂 打开产物文件夹 | `runs\\<项目>` |
| 📂 打开样张文件夹 | 该项目的 `samples\\` |
| 📂 打开 ComfyUI 的 LoRA 目录 | `F:\\…\\ComfyUI\\models\\loras` |
| 🪟 产物列表 | 弹窗列出所有 `.safetensors`，可「打开所在文件夹」/「装进 ComfyUI」 |
| 🗑 一键清理全部产物 | 移走 `*.safetensors` / `optimizer.pt` / `samples\\`（日志、配方保留） |
| 清空产物回收站 | 真删 `runs\\_deleted\\<项目>_*`，不可恢复 |

LoRA 行右侧 `✕` 删单个；样张 hover 出 `✕` 单删。产物目录结构：

```
runs\\<项目>\\qwen_<项目>.safetensors   ← LoRA 本体（约 76 MB @ rank16）
             qwen_<项目>_000000250.safetensors  ← 中途存档
             optimizer.pt              ← 续训用，可删
             config.yaml / train.log
             samples\\*.jpg             ← 样张（过程截图，不是模型）
```

## 四、素材怎么准备（决定成败）

```
E:\ai-train\datasets\qwen_<名字>\
  control\  001.png  002.png …        ← 要改的图（原图）
  target\   001.png  002.png …        ← 改完的样子（**必须同名**）
  target\   001.txt  002.txt …        ← caption（与 target 图片同名、同目录）
```

### 硬要求

| 项 | 要求 | 原因 |
|---|---|---|
| **配对** | `control/001.png` ↔ `target/001.png`，**去掉扩展名后同名** | 训练器只按文件名对应；对不上就是两个孤立文件 |
| **一对之内** | 必须**同一主体、同一构图**，只有“那个改动”不同 | 否则模型学的是“换人/换景”而不是你的操作 |
| 不同对之间 | 可以换人、换场景 | 这样才能学到“规律”而不是记住某张图 |
| **数量** | **≥30 对**（50~100 更稳） | 少于 20 对基本学不出稳定效果 |
| 尺寸 | 长边 1024 附近（≥768），16 的倍数 | 太小信息不够；程序会自动裁整 |
| 改动一致性 | 每对做的是**同一件事** | 一张换底一张改脸 → 学成四不像 |
| **不能两张一样** | control ≠ target | 一样等于教它“别改”，最常见的失败 |

### caption 怎么写

一句话，**动作 + 目标**，**所有对用同一套措辞**（统一措辞 = 免费得到触发词）：

```
✅ 把照片改成日式漫画风格，保留人物五官、姿势和构图
✅ 把背景换成纯白，保留商品和它自己的投影，整体提亮
❌ 好看一点                 （太虚）
❌ 换背景+改颜色+加文字       （一次太多件事）
❌ 写“漫画风格”但 target 是照片 （指令和答案矛盾，模型会学会无视指令）
```

## 五、训练要多久

| 阶段 | 512×512 | 1024×1024 |
|---|---|---|
| 加载模型（DiT + 文本编码器 + VAE） | 2~4 分钟 | 同 |
| 缓存 caption 文本向量 | 每条约 1 秒 | 同 |
| 训练每步 | **2.4 秒** | 约 6~10 秒（未实测） |
| 出样张 | 每张约 27 秒 | 更慢 |

| 场景 | 配置 | 总耗时 |
|---|---|---|
| **快速测试（只验证管线）** | 2 对 / 20 步 / 512 / 跳过基线样张 | **约 4~5 分钟** |
| 小规模试训 | 10~15 对 / 300~500 步 / 512 | 20~40 分钟 |
| **正常训练** | 30~50 对 / 1000~1500 步 / 1024 | 数小时（建议睡前跑） |

## 六、训练结束后会发生什么（自动清理）

训练进程结束（无论成功/失败/中断）都会自动：

| 动作 | 说明 |
|---|---|
| ① 杀残留训练进程 | 防孤儿进程继续占显存 |
| ② 修剪内存 | 把网页进程的工作集还给系统 |
| ③ 报告显存回落 | 进度区显示「显存 15.7 GB → 2.4 GB」 |
| ④ 决定 ComfyUI 去留 | 默认自动拉回；勾了「训练后不恢复」则保持关闭并给恢复按钮 |

> 说明：真正释放显存靠的是**训练进程退出**（退出后驱动立即回收）；本功能保证它**干净退出**、不留残余，并把结果量化给你看。

## 八、排错速查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 浏览器打不开 8198 | 服务没起/窗口被关 | 双击 BAT，看黑窗口报错 |
| BAT 一闪就退 | 8198 已被占用 | 说明已在跑，直接开浏览器 |
| **校验：没有可用的配对** | control 与 target **文件名不同** | 用「配对工具」配成一对（会自动改名） |
| 卡片红框「缺另一半」 | 只有一边 | 补另一边，或用配对工具 |
| 校验：缺 caption | 没写指令 | 「批量填 caption」或逐张填 |
| 点开始训练没反应 | 校验没过 / 已有训练在跑 | 顶部红条会写明原因 |
| **提示"检测到已有训练进程在跑"** | 你从命令行跑过 `run.py`（网页看不到它） | 等它结束，或先在命令行停掉 |
| 日志卡 `Loading text encoder` 很久 | 正常（8.7 GB 文本编码器在 CPU 反量化） | 等 2~4 分钟；超过 10 分钟且 GPU/CPU 都不动才需管 |
| 报 OOM / 训练崩 | 8189 没停 / 分辨率太大 | 勾停 ComfyUI，分辨率降到 512 |
| 进度条不动、step 一直 0 | 还在加载或出基线样张 | 看日志最后一行 |
| **改了步数结果"秒结束"** | 断点续训：目录里有上次检查点，metadata 步数 ≥ 新步数 | 删 `runs\<项目>\*.safetensors` 和 `optimizer.pt` 再训 |
| 样张全是噪点/糊 | 步数太少 / lr 太大 | lr→5e-5，步数 1000+ |
| 装了 LoRA 没变化 | 权重低 / 没挂上 / 底座不对 | 权重先 1.0 试；确认 2.1 底座 |
| 删错了想找回 | 删除是移到 `_deleted\` | `datasets\<项目>\_deleted\<时间戳>\` 里搬回（名字前有 `control_`/`target_` 前缀，要改回来） |
| 页面还是旧的 | 浏览器缓存 | 页面已发 `no-store`；仍旧就 Ctrl+F5，看页头 `build` 是否更新 |
| 「打开文件夹」不弹窗 | 服务不在你的桌面会话 | 双击 BAT 自己启动服务 |
| **页面显示"训练中"但实际没跑、按钮灰着点不动** | 浏览器缓存了 `/api/status`（已修为接口全部 no-store） | 硬刷 Ctrl+Shift+R；仍不对看顶部红条 |
| **点按钮毫无反应** | 页面脚本中断（元素被删但 JS 还在绑） | 刷新后看顶部红条 `⚠ 页面缺少元素：xxx`，把这条发我 |
| 日志区一直「（还没有日志）」 | 旧版只认"当前训练"的日志 | 已改为按项目取日志，刷新即可 |
| 手动「停止」后显示"训练报错：退出码 1" | 旧版把 kill 当异常 | 已修（manual_stop 标记） |

## 十一、已知限制

1. **最多 4 路参考图**（`control` / `control_2` / `control_3` / `control_4`）—— ai-toolkit 的 `qwen_image_2` 扩展支持到这里，再多要改配方手动加
2. **底座只认 Qwen-Image 2.1**：其它架构的下拉里置灰（选了也训不了）
3. **一次只能训一个**：网页内置锁 + 外部训练进程检测
4. **「打开文件夹」依赖会话**：服务必须跑在你的桌面会话里
5. **能力型训练（提升多图指令遵循）需要大量多样性数据**：30 对只够学会「你这几种组合」，泛化要 200+ 对且指令句式多样
6. 未做：开机自启、任务队列、LoRA 评测台
